# * One block per character (gamevar CHAR, 0..18 as DATA/STATIC.CON); each weapon slot's icon is read at
#   draw time from the CON gamearray WEAPON_TILE[slot] (array:WEAPON_TILE), which each character's
#   PLAYER/CHAR/*.CON sets for the gun of the loadout the player bought. "fallback T" is the character's
#   stock gun, used when the array holds nothing usable. Slot 11 (expander-like alternate of slot 6) has
#   no WEAPON_TILE element of its own, so it shows element 6.
# * wristhud rest 0.6 ... unless: the HUD below 60% of the screen goes onto the wrists, except while a
#   full-screen CON terminal/menu is up (mouse cursor mode, PC terminal, mission box, character select,
#   research/bestiary, documents): those stay whole in front.
#
# Slots are native curr_weapon slots (CON cur_weap is a copy of player[].curr_weapon, PLAYER.CON:119):
# 0 temp weapon (picked up from enemies; fists/kick when none), 1 pistol, 2 shotgun, 3 machinegun,
# 4 rocket launcher, 5 grenade/pipebomb, 6 special 1 (+ 11, its expander-like alternate; key 7 toggles
# 6 and 11 as in Duke), 7 special 2, 8 trap/tripbomb, 9 special 3. Slot N is key N+1 (Weapon_1..10).
# Slot 10 (remote detonator, set by script in INPUT/ALT_FIRE.CON:556) has no key and is not listed.

# Slot 0: the same for everybody. The temp weapon's icon is in WEAPON_TILE[0] (set per pickup) and cannot
# be named here, so the wheel shows the key number. noammo: its rounds live in AMC's ammo pools
# (ammo_getdefs/ammo_remaining, DISPLAY/WEAPONBAR.CON:54-61), not always in ammo_amount[0].
weapon 0 none noammo

# The game's HUD is drawn in EVENT_DISPLAYREST (DISPLAY/DISPLAY.CON:2091), in 320x200 units. Per-character
# bars sit at y>=124 (most at 150-191), centre prompts and fullscreen overlays at y 100-110. 0.6 (y=120)
# sends the bars to the wrists and keeps the centre prompt (default position 170,110) in front.
# Gamevars of the full-screen screens (NOTES.md section 5): MOUSEUP cursor mode, PCINTER computer terminal,
# MISSION_UP mission box, CHARSELECT character select, show_rs_ui/show_bst_ui research and bestiary,
# DOCUMENT (-1 when none).
wristhud rest 0.6 unless MOUSEUP unless PCINTER unless MISSION_UP unless CHARSELECT unless show_rs_ui unless show_bst_ui unless DOCUMENT not -1

# AMC's own mouse cursor (PLAYER.CON:3143-3165): while MOUSEUP > 0 the script adds the turn and look input
# to Q16_MOUSEX/Q16_MOUSEY (16.16, 320x200), draws the cursor there (GENERIC_UI.CON:125) and clicks on Fire.
# The VR layer sets those gamevars from the laser instead. Only MOUSEUP is listed: every screen that reads
# MOUSEX/MOUSEY (character select CHARSELECT.CON:108-111, the PC terminals INTERFACES.CON:307 and the
# research/bestiary UIs reached through them, loadout/shops, CIVILIANS.CON dialogues) sets MOUSEUP 1 itself,
# while PCINTER/CHARSELECT/show_*_ui can stay non-zero with no cursor; MISSION_UP (the PDA box) and
# DOCUMENT (full-screen pictures) never read the cursor.
cursor Q16_MOUSEX Q16_MOUSEY when MOUSEUP
